# Security Access Policy

Acme Enterprise requires role-based access control for all internal knowledge systems.
Every user must authenticate through single sign-on and inherit access from approved
department roles. Sensitive records are separated into finance, security, compliance,
and executive scopes.

Quarterly access reviews must verify that inactive users, contractors, and transferred
employees no longer retain privileged roles. Exceptions require a compliance ticket,
a named approver, and an expiration date.

The knowledge assistant must never answer from records outside the user's authorized
roles. Retrieval traces should include the source title, source type, and confidence
indicator for every answer.
